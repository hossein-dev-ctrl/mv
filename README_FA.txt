نصب روی پروژه
۱. فایل‌های پوشه project در ZIP را روی ریشه پروژه جایگزین کنید.
   changes.patch روش جایگزین است؛ هر دو روش را همزمان اجرا نکنید.
۲. سرور توسعه را متوقف کنید و این دستورها را اجرا کنید:
   npx prisma migrate deploy
   npx prisma generate
۳. برای ابزار تست، در فایل .env این مقدار را اضافه کنید:
   DEV_TEST_USERS_ENABLED=true
۴. npm run dev
نیازی به prisma migrate reset یا حذف داده‌ها نیست. وابستگی جدیدی اضافه نشده است.

مدرک کجا ساخته می‌شود؟
/admin اکنون کارت مستقل مرکز گواهی‌نامه و طراحی قالب دارد.
/admin/certificates: دوره را انتخاب کنید؛ دانش‌آموز، کارنامه و دکمه دریافت مدرک را می‌بینید.
صدور همچنین از کارنامه نهایی دانش‌آموز در پنل خودش و پنل مدرسِ همان دوره ممکن است.
شرایط: تکمیل همه درس‌ها و ویدئوها، تصحیح تمام تمرین‌های منتشرشده و حداقل نمره ۶۰
هم در آزمون و هم در کارنامه نهایی. کلیک مدیر این شروط را دور نمی‌زند.
صدور مجدد همان گواهی قبلی را برمی‌گرداند؛ گواهی تکراری ساخته نمی‌شود.
/admin/certificates فهرست، مشاهده و ابطال مدارک را هم دارد.
/dashboard/certificates: مدارک دانش‌آموز.
/certificates/شناسه: نمایش عمومی، وضعیت استعلام و چاپ یا ذخیره PDF مرورگر.

چند طراحی مختلف
/admin/certificates/templates
سه سبک کلاسیک رسمی، مدرن و رنگی کودک و نوجوان وجود دارد.
از هر سبک چند قالب با نام، رنگ، عنوان فارسی و انگلیسی مجموعه و نام تأییدکننده بسازید.
پیش‌نمایش زنده است. سپس در پایین صفحه برای هر دوره یک قالب انتخاب کنید.
بدون انتخاب، قالب کلاسیک پیش‌فرض استفاده می‌شود؛ مدارک قدیمی نیز همین ظاهر را دارند.
طراحی در لحظه صدور داخل مدرک ذخیره می‌شود. ویرایش قالب، ظاهر مدارک قبلی را عوض نمی‌کند.
غیرفعال‌کردن قالب به مدارک قبلی آسیب نمی‌زند؛ برای صدور جدید دوره باید قالب فعال انتخاب شود.
این مرحله شامل بارگذاری تصویر پس‌زمینه/امضا یا ویرایشگر آزاد طراحی نیست.
مدرک شامل عنوان دو‌زبانه، نام دانش‌آموز، دوره، نمره، تاریخ، شناسه و QR است.
نام دانش‌آموز و نام دوره خودکار ترجمه نمی‌شوند؛ متن ثبت‌شده نمایش داده می‌شود.
برای QR نشانی قابل دسترس سایت را تنظیم کنید:
PUBLIC_SITE_URL=https://your-domain.example
اسکن QR با موبایل، localhost رایانه را باز نمی‌کند؛ برای تست QR نشانی قابل دسترس لازم است.

تست با یک شماره
با همان شماره مدیر واقعی وارد شوید، سپس /admin/testing را باز کنید.
«ساخت حساب‌ها و دوره‌های آزمایشی»: دو مدرس و دو دانش‌آموز مستقل، دو دوره رایگان
و برای هر دوره یک درس، یک تمرین و یک آزمون چهارگزینه‌ای ساخته می‌شود.
هر دانش‌آموز در دوره یکی از مدرس‌ها ثبت‌نام دارد. ساخت مجدد تکرار یا پاک‌سازی نمی‌کند.
این حساب‌ها شماره همراه ندارند؛ برای جابه‌جایی نیازی به پیامک جدید نیست.
با «ورود به این حساب» وارد نقش انتخاب‌شده می‌شوید. بالای پنل، نوار آزمایش و
«بازگشت به مدیر» وجود دارد. حساب اصلی مدیر و نقش آن تغییر نمی‌کند.
با دانش‌آموز اول درس را تکمیل و تمرین را ارسال کنید؛ آزمون را جواب دهید (پاسخ: چهار).
به مدیر بازگردید و با مدرس اول تمرین را نمره دهید؛ سپس کارنامه و صدور مدرک را تست کنید.
با مدرس دوم بررسی کنید مدیریت دوره و دانش‌آموز مدرس اول در دسترس نباشد.
تیکت، اعلان و سایر امکانات را هم بین همین حساب‌های مستقل می‌توانید امتحان کنید.
مدارک این حساب‌ها نشان آزمایشی دارند و در نسخه production قابل استعلام نیستند.
پرداخت مبلغ مثبت در حالت آزمایش فقط با ZARINPAL_SANDBOX=true ممکن است.
این ابزار فقط با npm run dev و فعال‌بودن DEV_TEST_USERS_ENABLED کار می‌کند.
در npm run build / npm start حتی با فعال بودن متغیر قابل استفاده نیست.
نشست آزمایشی دو ساعت اعتبار دارد. خروج عادی، بازگشت سریع را حذف می‌کند؛
در این حالت با همان شماره مدیر دوباره وارد شوید.
داده‌های تست در دیتابیس توسعه باقی می‌مانند. برای کار واقعی از دیتابیس جدا استفاده کنید.
دوره‌های مدرس آزمایشی در فهرست عمومی production نمایش داده نمی‌شوند.
